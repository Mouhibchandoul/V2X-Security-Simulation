# V2X Security Simulation

📌 Overview

This project focuses on the simulation and security assessment of V2X (Vehicle-to-Everything) communications in Intelligent Transportation Systems (ITS).

The objective is to study communication performance and evaluate the impact of different cyberattacks on connected vehicles.

🎯 Objectives

* Simulate vehicle mobility using SUMO
* Simulate V2X communications using NS-3
* Implement WAVE / IEEE 802.11p communication
* Generate and exchange BSM messages
* Apply cryptographic mechanisms for message authentication
* Simulate cybersecurity attacks
* Detect and evaluate malicious behavior
* Analyze communication performance

 🛠️ Technologies

* Python
* NS-3
* SUMO
* TraCI
* WAVE / IEEE 802.11p
* Cryptography
* Wireshark
* Docker

 🔐 Security

The project studies several security threats affecting V2X communications, including:

* GPS Spoofing
* Replay Attacks
* Sybil Attacks
* Denial-of-Service (DoS)

Authentication and cryptographic mechanisms are used to improve the security and integrity of exchanged messages.

 📊 Results

The simulation evaluates several network and security metrics:

* Packet Delivery Ratio (PDR)
* Communication latency
* Packet reception
* Impact of attacks
* Attack detection

 🏗️ Architecture

The solution combines:

SUMO → Vehicle Mobility

NS-3 → Network Simulation

Python → Security and Analysis

Dashboard → Results Visualization
